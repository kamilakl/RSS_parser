# RSS Feed Parser

A Python command-line RSS reader that retrieves and parses RSS 2.0 feeds and outputs formatted results or JSON.

This project parses RSS XML feeds, extracts structured article metadata, and prints formatted results to the console.

---

# Features

- Fetch RSS feeds from a URL
- Parse RSS 2.0 XML structure
- Extract article metadata (title, author, publication date, categories, description)
- Format output for console display
- Optional JSON output
- CLI arguments for feed limits
